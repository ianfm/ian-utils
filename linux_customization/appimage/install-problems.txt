LOL ok so running with --no-sandbox fixes that (chmod 4755 file did not) BUT it fails again with 
```
./AppRun: line 45: /nrfconnect: No such file or directory
```


The culprit is this bogus $1 in the AppRun script itself that evaluates to nothing and turns APPDIR into something useless.
```
if [ -z "$APPDIR" ] ; then
  # Find the AppDir. It is the directory that contains AppRun.
  # This assumes that this script resides inside the AppDir or a subdirectory.
  # If this script is run inside an AppImage, then the AppImage runtime likely has already set $APPDIR
  path="$(dirname "$(readlink -f "${THIS}")")"
  while [[ "$path" != "" && ! -e "$path/$1" ]]; do
    path=${path%/*}
  done
  APPDIR="$path"
fi
```

Fixed version: runs fine
```
if [ -z "$APPDIR" ] ; then
  # Find the AppDir. It is the directory that contains AppRun.
  # This assumes that this script resides inside the AppDir or a subdirectory.
  # If this script is run inside an AppImage, then the AppImage runtime likely has already set $APPDIR
  path="$(dirname "$(readlink -f "${THIS}")")"
  while [[ "$path" != "" && ! -e "$path/AppRun" ]]; do
    path=${path%/*}
  done
  APPDIR="$path"
fi

```
